# Cafeteria, site temporário

Site estático em HTML, CSS e JavaScript. O hero usa um clipe MP4 de 8 segundos e acompanha a rolagem em desktop. Em telas pequenas ou com movimento reduzido, usa um pôster estático.

## Prévia local

Execute `Abrir previa.cmd` para iniciar a prévia em `http://127.0.0.1:8000/`. O arquivo `index.html` aberto diretamente desativa o vídeo por usar `file://`.

## Arquivos

- `assets/hero-scrub.mp4`: vídeo do hero.
- `assets/hero-poster.jpg`: imagem usada enquanto o vídeo carrega ou como alternativa estática.
- `assets/main.js` e `assets/style.css`: interações e estilos.

## Antes de publicar

A marca, a cidade, os horários, o endereço, o contato e o cardápio ainda são campos provisórios. Substitua-os pelos dados reais da cafeteria antes de divulgar o site. As imagens são provisórias e devem ser trocadas por fotos reais da casa.
